工作四块｜我的个人工作台
👉 点击进入工作台
做这个工作台的想法很简单：把每天要做的事、正在推进的工作和常用入口放在一起，打开网页就能一目了然。简洁明了，为工作而生，谁都可以用。

主要分成四块：
- 工作产出：论文进度、家教记录、自媒体选题与分析。
- 学习计划：英语打卡、读书计划。
- 机会搜寻：求职记录，以及考公、事业单位、选调、私企、国企、外企网址分类。
- 技能树：记录技能成长，整理图片、PDF 作品集。
另外还有每日规划、复盘和个人状态总结，帮自己理清每天的节奏。常用网址点一下就能打开，也可以收藏本地文件地址；本地文件受浏览器限制，部分需要复制路径打开。

用邮箱注册后，就能在网页端保存和同步自己的记录。项目免费开放，计划长期免费；云端空间有限，也受第三方免费服务规则影响。文字记录可以导出到本地长期保存，图片和 PDF 原件记得另外备份。

构建过程也很简单：我负责提需求、调布局，大部分代码由 AI 完成，再通过 GitHub Pages 和 Supabase 上线。从“我想要一个这样的工具”到真的能用，还是忍不住感慨一句：GPT 真牛逼。
