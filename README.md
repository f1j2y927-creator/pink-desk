# 粉粉工作台

入口文件为 `index.html`，无需安装依赖。

## 更新网页

在 GitHub 打开 `index.html`，点击编辑按钮，修改后提交（Commit changes）。也可以通过 Add file → Upload files 上传更新后的文件，文件名须为 `index.html`。

## 在线访问

在仓库 Settings → Pages 中选择 Deploy from a branch，再选择 main 分支和 / (root)，保存。部署成功后访问 https://f1j2y927-creator.github.io/pink-desk/ 。

## 数据备份

待办、笔记等数据保存在当前浏览器的 localStorage，不会随代码上传 GitHub，也不会自动跨设备同步。从本地文件切换到在线地址前，请在原网页导出备份，然后在在线网页导入。清除浏览器数据前也应备份。

仓库中的网页源代码公开可见，请勿写入密码或私人信息。
